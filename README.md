# News Sentiment Analysis

## Project Overview

News Sentiment Analysis is an automated system designed to
collect news articles, analyze their sentiment, store the
processed information, and provide an interactive dashboard
for visualization and analysis.

## Objectives

- Automatically collect news articles
- Process and clean news data
- Perform sentiment analysis
- Store processed news data
- Store raw news data
- Provide an interactive dashboard
- Deploy the application using AWS services
